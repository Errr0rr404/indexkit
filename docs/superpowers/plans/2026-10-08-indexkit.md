# Indexkit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `indexkit`, an open-source Node CLI that reads a local web app, turns its pages into absolute URLs, submits one sitemap to Google Search Console, checks index status through the URL Inspection API, and skips URLs that are already indexed.

**Architecture:** Static framework parsers turn the project tree into route records. A sample expander and a private-path policy decide which URLs are concrete and public. SQLite remembers every URL, its source hash, and the last Search Console verdict. The daily command writes a sitemap, inspects only pending URLs, and optionally notifies IndexNow. MiniMax is called only when the framework is unrecognized, and optionally to label public versus private routes. The model result is cached and checked against the files that were actually sent.

**Tech Stack:** Node.js 22.5+ (this machine is v24), TypeScript ESM, Vitest, `node:sqlite`, `google-auth-library`, `fetch`.

## Global Constraints

- Package name is `indexkit`. License is MIT. Copyright line is `Copyright 2026 Indexkit contributors`.
- Node engine is `>=22.5`. Module format is ESM. Internal imports use the `.js` suffix.
- Google submission is `webmasters.sitemaps.submit` of one sitemap URL. Google status reads are `urlInspection.index.inspect`.
- The Indexing API (`indexing.googleapis.com`) is out of scope. Browser automation of Search Console is out of scope. Extra Cloud projects or service accounts for more quota are out of scope.
- Default inspection budget is `200`. The hard ceiling in config validation is `2000`.
- A URL whose verdict is `indexed` and whose source hash is unchanged is not inspected again.
- A URL whose verdict is `error` is retried only after 24 hours.
- Dynamic routes stay out of the sitemap unless `samples` provides a value for every parameter. Expansion above 100 URLs for one route is rejected.
- Paths under `/api`, `/admin`, `/auth`, `/login`, `/logout`, `/signup`, `/sign-in`, `/sign-up`, `/account`, `/settings`, `/dashboard`, `/internal`, `/health`, and `/_next` are stored and marked `indexable: false`.
- Secrets stay in the environment or in a gitignored credential file. `MINIMAX_API_KEY` is the only MiniMax credential. No key is printed, logged, or committed.
- Tests use `node:sqlite`, temp directories, and injected `fetch`. Tests do not call Google, MiniMax, or IndexNow.
- Removed routes stay in the ledger. v1 does not delete history.
- OAuth and service-account credentials are both supported. The Search Console scope is `https://www.googleapis.com/auth/webmasters`.
- `siteUrl` is the Search Console property string, copied exactly (`sc-domain:example.com` or `https://example.com/`).

## Product decisions already made

- Opening a URL in Chrome does not index it.
- The URL Inspection API returns status. It has no request-indexing method. Quota is about 2,000 inspections per day and 600 per minute per property.
- The Indexing API is limited by Google to `JobPosting` and `BroadcastEvent` inside a `VideoObject`. This tool is for ordinary app routes, so it does not call that API.
- IndexNow reaches Bing, Yandex, Naver, Seznam, Yep, and Amazon. It does not reach Google. It is an optional second channel.
- The supported way to hand Google the full URL list is a sitemap submitted once per change.

`src/fsutil.ts`

```ts
import { createHash } from "node:crypto";
import fs from "node:fs";
import path from "node:path";

const SKIP_DIRS = new Set([
  "node_modules",
  "dist",
  ".git",
  ".indexkit",
  "coverage",
  ".next",
  ".svelte-kit",
  ".nuxt",
  ".astro",
]);

export function walkFiles(root: string, accept: (abs: string) => boolean): string[] {
  const out: string[] = [];
  function visit(dir: string): void {
    if (!fs.existsSync(dir)) return;
    for (const entry of fs.readdirSync(dir, { withFileTypes: true })) {
      if (SKIP_DIRS.has(entry.name)) continue;
      const abs = path.join(dir, entry.name);
      if (entry.isDirectory()) visit(abs);
      else if (accept(abs)) out.push(abs);
    }
  }
  visit(root);
  return out.sort();
}

export function hashFile(abs: string): string {
  const hash = createHash("sha256");
  hash.update(fs.existsSync(abs) ? fs.readFileSync(abs) : abs);
  return hash.digest("hex");
}

`src/routes.ts`

```ts
import type { RawRoute, RouteRecord } from "./types.js";

const PRIVATE = /^\/(api|admin|auth|login|logout|signup|sign-in|sign-up|account|settings|dashboard|internal|health|_next)(\/|$)/i;
const PARAM = /\[\[\.\.\.([^\]]+)\]\]|\[\.\.\.([^\]]+)\]|\[([^\]]+)\]|:([A-Za-z_][A-Za-z0-9_]*)/g;

export function toUrl(origin: string, routePath: string): string {
  const base = origin.replace(/\/+$/, "");
  if (routePath === "/" || routePath === "") return `${base}/`;
  return `${base}${routePath.startsWith("/") ? routePath : `/${routePath}`}`;
}

function paramNames(routePath: string): string[] {
  const names: string[] = [];
  for (const match of routePath.matchAll(PARAM)) {
    const name = match[1] || match[2] || match[3] || match[4];
    if (name) names.push(name);
  }
  return names;
}

function withPolicy(route: RouteRecord): RouteRecord {
  if (!route.indexable) return route;
  if (PRIVATE.test(route.path)) {
    return { ...route, indexable: false, reason: "private path" };
  }
  return route;
}

export function finalizeRoutes(raw: RawRoute[], samples: Record<string, string[]> = {}): RouteRecord[] {
  const finished: RouteRecord[] = [];
  for (const route of raw) {
    const names = paramNames(route.path);
    if (names.length === 0) {
      finished.push(withPolicy({
        ...route,
        dynamic: false,
        indexable: true,
        reason: "static route",
      }));
      continue;
    }
    const missing = names.filter((name) => !samples[name] || samples[name].length === 0);
    if (missing.length > 0) {
      finished.push({
        ...route,
        dynamic: true,
        indexable: false,
        reason: `dynamic segment needs samples: ${missing.join(", ")}`,
      });
      continue;
    }
    let paths = [route.path];
    let tooMany = false;
    for (const name of names) {
      const next: string[] = [];
      for (const current of paths) {
        for (const value of samples[name] ?? []) {
          const pattern = new RegExp(
            `\\[\\[\\.\\.\\.${name}\\]\\]|\\[\\.\\.\\.${name}\\]|\\[${name}\\]|:${name}(?![A-Za-z0-9_])`,
          );
          next.push(current.replace(pattern, encodeURIComponent(value)));
        }
      }
      paths = next;
      if (paths.length > 100) {
        tooMany = true;
        break;
      }
    }
    if (tooMany) {
      finished.push({
        ...route,
        dynamic: true,
        indexable: false,
        reason: "sample expansion exceeds 100 urls",
      });
      continue;
    }
    for (const path of paths) {
      finished.push(withPolicy({
        ...route,
        path,
        dynamic: false,
        indexable: true,
        reason: "sample expansion",
      }));
    }
  }
  const seen = new Set<string>();
  return finished.filter((route) => {
    const key = `${route.path}\0${route.sourcePath}`;
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}

```ts
import fs from "node:fs";
import path from "node:path";
import type { RawRoute } from "../types.js";

const PAGE_FILES = ["page.tsx", "page.ts", "page.jsx", "page.js", "page.mdx"];

function appRoots(project: string): string[] {
  return ["app", "src/app"].map((rel) => path.join(project, rel)).filter((abs) => fs.existsSync(abs));
}

function isRouteGroup(name: string): boolean {
  return name.startsWith("(") && name.endsWith(")") && !name.startsWith("(.") && !name.startsWith("(..");
}

function isIgnoredDir(name: string): boolean {
  return name.startsWith("_") || name.startsWith("@") || name.startsWith("(.") || name.startsWith("(..");
}

function walk(project: string, dir: string, urlParts: string[], routes: RawRoute[]): void {
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  const page = PAGE_FILES.find((name) => entries.some((entry) => entry.isFile() && entry.name === name));
  if (page) {
    const routePath = urlParts.length === 0 ? "/" : `/${urlParts.join("/")}`;
    routes.push({
      path: routePath,
      sourcePath: path.relative(project, path.join(dir, page)),
      dynamic: urlParts.some((part) => part.includes("[")),
    });
  }
  for (const entry of entries) {
    if (!entry.isDirectory()) continue;
    if (isIgnoredDir(entry.name)) continue;
    const nextParts = isRouteGroup(entry.name) ? urlParts : [...urlParts, entry.name];
    walk(project, path.join(dir, entry.name), nextParts, routes);
  }
}

export function discoverNextApp(project: string): RawRoute[] {
  const routes: RawRoute[] = [];
  for (const root of appRoots(project)) walk(project, root, [], routes);
  return routes.sort((a, b) => a.path.localeCompare(b.path));
}

import path from "node:path";
import { walkFiles } from "../fsutil.js";
import type { RawRoute } from "../types.js";

const PAGE_EXT = /\.(js|jsx|ts|tsx|mdx)$/;

export function discoverNextPages(project: string): RawRoute[] {
  const roots = ["pages", "src/pages"].map((rel) => path.join(project, rel));
  const routes: RawRoute[] = [];
  for (const root of roots) {
    const files = walkFiles(root, (abs) => PAGE_EXT.test(abs));
    for (const abs of files) {
      const rel = path.relative(root, abs).split(path.sep).join("/");
      if (rel === "api" || rel.startsWith("api/")) continue;
      const withoutExt = rel.replace(PAGE_EXT, "");
      const parts = withoutExt.split("/");
      if (parts.some((part) => part.startsWith("_"))) continue;
      const urlParts = parts.filter((part) => part !== "index");
      routes.push({
        path: urlParts.length === 0 ? "/" : `/${urlParts.join("/")}`,
        sourcePath: path.relative(project, abs),
        dynamic: urlParts.some((part) => part.includes("[")),

import fs from "node:fs";
import path from "node:path";
import type { RawRoute } from "../types.js";

const PAGE_FILES = ["+page.svelte", "+page.ts", "+page.js", "+page.server.ts", "+page.server.js"];

function walk(project: string, dir: string, urlParts: string[], routes: RawRoute[]): void {
  if (!fs.existsSync(dir)) return;
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  const page = PAGE_FILES.find((name) => entries.some((entry) => entry.isFile() && entry.name === name));
  if (page) {
    routes.push({
      path: urlParts.length === 0 ? "/" : `/${urlParts.join("/")}`,
      sourcePath: path.relative(project, path.join(dir, page)),
      dynamic: urlParts.some((part) => part.includes("[")),
    });
  }
  for (const entry of entries) {
    if (!entry.isDirectory() || entry.name.startsWith("_")) continue;
    const grouped = entry.name.startsWith("(") && entry.name.endsWith(")");
    const nextParts = grouped ? urlParts : [...urlParts, entry.name];
    walk(project, path.join(dir, entry.name), nextParts, routes);
  }
}

export function discoverSvelteKit(project: string): RawRoute[] {
  const routes: RawRoute[] = [];
  walk(project, path.join(project, "src/routes"), [], routes);
  return routes.sort((a, b) => a.path.localeCompare(b.path));
}

import path from "node:path";
import { walkFiles } from "../fsutil.js";
import type { RawRoute } from "../types.js";

const EXT = /\.(js|jsx|ts|tsx|md|mdx)$/;

function fromFile(rel: string): { path: string; dynamic: boolean } | null {
  const base = rel.replace(EXT, "");
  if (base.endsWith(".server") || base.endsWith(".test") || base.endsWith(".spec")) return null;
  const segments = base.split(".").flatMap((segment) => {
    if (segment === "_index" || segment === "index") return [];
    if (segment.startsWith("_")) return [];
    if (segment.startsWith("$")) return [`:${segment.slice(1)}`];
    return [segment];
  });
  return {
    path: segments.length === 0 ? "/" : `/${segments.join("/")}`,
    dynamic: segments.some((segment) => segment.startsWith(":")),
  };
}

export function discoverRemix(project: string): RawRoute[] {
  const roots = ["app/routes", "src/routes", "routes"];
  const routes: RawRoute[] = [];
  for (const relRoot of roots) {
    const root = path.join(project, relRoot);
    for (const abs of walkFiles(root, (file) => EXT.test(file))) {
      const rel = path.relative(root, abs).split(path.sep).join("/");
      const mapped = fromFile(rel);
      if (!mapped) continue;
      routes.push({ ...mapped, sourcePath: path.relative(project, abs) });
    }
  }
  return routes.sort((a, b) => a.path.localeCompare(b.path) || a.sourcePath.localeCompare(b.sourcePath));
}

import fs from "node:fs";
import path from "node:path";
import { walkFiles } from "../fsutil.js";
import type { RawRoute } from "../types.js";

const CALL = /(?:^|[^.\w])(?:app|router|server)\.(get|head)\(\s*['"`](\/[^'"`]*)['"`]/g;
const SOURCE = /\.(js|jsx|ts|tsx|mjs|cjs)$/;

export function discoverExpress(project: string): RawRoute[] {
  const routes: RawRoute[] = [];
  const seen = new Set<string>();
  for (const abs of walkFiles(project, (file) => SOURCE.test(file))) {
    const text = fs.readFileSync(abs, "utf8");
    for (const match of text.matchAll(CALL)) {
      const routePath = match[2];
      if (!routePath || routePath.includes(":") || routePath.includes("*")) continue;
      if (seen.has(routePath)) continue;
      seen.add(routePath);
      routes.push({
        path: routePath,
        sourcePath: path.relative(project, abs),
        dynamic: false,
      });
    }
  }
  return routes.sort((a, b) => a.path.localeCompare(b.path));
}

import fs from "node:fs";
import path from "node:path";
import type { Framework, RawRoute } from "../types.js";
import { discoverAstro } from "./astro.js";
import { discoverExpress } from "./express.js";
import { discoverNextApp } from "./next-app.js";
import { discoverNextPages } from "./next-pages.js";
import { discoverNuxt } from "./nuxt.js";
import { discoverRemix } from "./remix.js";
import { discoverSvelteKit } from "./sveltekit.js";

function exists(project: string, rel: string): boolean {
  return fs.existsSync(path.join(project, rel));
}

export function detectFramework(project: string): Framework {
  if (discoverNextApp(project).length > 0) return "next-app";
  if (discoverSvelteKit(project).length > 0) return "sveltekit";
  if (["astro.config.mjs", "astro.config.ts", "astro.config.js"].some((rel) => exists(project, rel))) return "astro";
  if (["nuxt.config.ts", "nuxt.config.js", "nuxt.config.mjs"].some((rel) => exists(project, rel))) return "nuxt";
  if (discoverNextPages(project).length > 0) return "next-pages";
  if (discoverRemix(project).length > 0 && discoverSvelteKit(project).length === 0) return "remix";
  if (discoverExpress(project).length > 0) return "express";
  return "unknown";
}

export function discoverRaw(project: string): { framework: Framework; routes: RawRoute[] } {
  const framework = detectFramework(project);
  const routes =
    framework === "next-app" ? discoverNextApp(project) :
    framework === "sveltekit" ? discoverSvelteKit(project) :
    framework === "astro" ? discoverAstro(project) :
    framework === "nuxt" ? discoverNuxt(project) :
    framework === "next-pages" ? discoverNextPages(project) :
    framework === "remix" ? discoverRemix(project) :
    framework === "express" ? discoverExpress(project) :
    [];
  return { framework, routes };
}

import type { RawRoute, RouteRecord } from "./types.js";
import { discoverRaw } from "./discover/detect.js";
import { finalizeRoutes } from "./routes.js";

export interface RouteModel {
  discoverFromFiles(input: { project: string; files: { path: string; text: string }[] }): Promise<RawRoute[]>;
  classify(routes: RouteRecord[]): Promise<RouteRecord[]>;
}

export async function collectRoutes(opts: {
  project: string;
  samples?: Record<string, string[]>;
  model?: RouteModel | null;
  filesForModel?: { path: string; text: string }[];
}): Promise<{ framework: import("./types.js").Framework; routes: RouteRecord[] }> {
  const found = discoverRaw(opts.project);
  let raw = found.routes;
  if (raw.length === 0 && opts.model) {
    raw = await opts.model.discoverFromFiles({
      project: opts.project,
      files: opts.filesForModel ?? [],
    });
  }
  let routes = finalizeRoutes(raw, opts.samples);
  if (opts.model && routes.length > 0) {
    const classified = await opts.model.classify(routes);
    const allowed = new Set(routes.map((route) => route.path));
    routes = classified.filter((route) => allowed.has(route.path));
  }
  return { framework: found.framework, routes };
}

import fs from "node:fs";
import path from "node:path";
import type { IndexkitConfig } from "./types.js";

export function loadConfig(
  cwd: string,
  overrides: Partial<IndexkitConfig> & { configPath?: string } = {},
): IndexkitConfig {
  const configPath = overrides.configPath ?? path.join(cwd, "indexkit.config.json");
  const fromFile = fs.existsSync(configPath)
    ? JSON.parse(fs.readFileSync(configPath, "utf8")) as Partial<IndexkitConfig>
    : {};
  const merged: IndexkitConfig = {
    ...fromFile,
    ...stripEmpty(overrides),
    project: path.resolve(cwd, overrides.project ?? fromFile.project ?? "."),
    origin: overrides.origin ?? fromFile.origin ?? "",
    budget: overrides.budget ?? fromFile.budget ?? 200,
  };
  if (!merged.origin || !/^https?:\/\//.test(merged.origin)) {
    throw new Error("origin must be an absolute http(s) URL");
  }
  if (!fs.existsSync(merged.project)) {
    throw new Error(`project does not exist: ${merged.project}`);
  }
  if (!Number.isInteger(merged.budget) || (merged.budget ?? 0) < 1 || (merged.budget ?? 0) > 2000) {
    throw new Error("budget must be an integer from 1 to 2000");
  }
  return merged;
}

function stripEmpty(overrides: Partial<IndexkitConfig> & { configPath?: string }): Partial<IndexkitConfig> {
  const copy: Partial<IndexkitConfig> = { ...overrides };
  delete (copy as { configPath?: string }).configPath;
  for (const key of Object.keys(copy) as (keyof IndexkitConfig)[]) {
    if (copy[key] === undefined) delete copy[key];
  }
  return copy;
}

import fs from "node:fs";
import path from "node:path";
import { DatabaseSync } from "node:sqlite";
import type { LedgerRow, Verdict } from "./types.js";

const VERDICTS: Verdict[] = [
  "unknown",
  "indexed",
  "discovered",
  "crawled_not_indexed",
  "excluded",
  "error",
  "stale",
];

export interface Ledger {
  upsert(input: { url: string; path: string; sourcePath: string; sourceHash: string; indexable: boolean }, now: string): "inserted" | "unchanged" | "stale";
  markInspection(url: string, result: { verdict: Verdict; coverageState: string | null; lastCrawlTime: string | null } | { error: string }, inspectedAt: string): void;
  listPending(budget: number, nowIso: string): LedgerRow[];
  counts(): Record<Verdict, number> & { private: number };
  indexableUrls(): { url: string; sourcePath: string }[];
  markSitemap(urls: string[], at: string): void;
  urlsNeedingIndexNow(): string[];
  markIndexNow(urls: string[], at: string): void;
  close(): void;
}

export function openLedger(dbPath: string): Ledger {
  fs.mkdirSync(path.dirname(dbPath), { recursive: true });
  const db = new DatabaseSync(dbPath);
  db.exec(`
    CREATE TABLE IF NOT EXISTS urls (
      url TEXT PRIMARY KEY,
      path TEXT NOT NULL,
      source_path TEXT NOT NULL,
      source_hash TEXT NOT NULL,
      indexable INTEGER NOT NULL,
      verdict TEXT NOT NULL,
      coverage_state TEXT,
      last_crawl_time TEXT,
      last_inspected_at TEXT,
      last_sitemap_at TEXT,
      indexnow_at TEXT,
      last_error TEXT,
      updated_at TEXT NOT NULL
    )
  `);

  return {
    upsert(input, now) {
      const existing = db.prepare("SELECT source_hash FROM urls WHERE url = ?").get(input.url) as { source_hash: string } | undefined;
      if (!existing) {
        db.prepare(`
          INSERT INTO urls (url, path, source_path, source_hash, indexable, verdict, updated_at)
          VALUES (?, ?, ?, ?, ?, 'unknown', ?)
        `).run(input.url, input.path, input.sourcePath, input.sourceHash, input.indexable ? 1 : 0, now);
        return "inserted";
      }
      if (existing.source_hash === input.sourceHash) {
        db.prepare("UPDATE urls SET path = ?, source_path = ?, indexable = ?, updated_at = ? WHERE url = ?")
          .run(input.path, input.sourcePath, input.indexable ? 1 : 0, now, input.url);
        return "unchanged";
      }
      db.prepare(`
        UPDATE urls
        SET path = ?, source_path = ?, source_hash = ?, indexable = ?, verdict = 'stale', last_error = NULL, updated_at = ?
        WHERE url = ?
      `).run(input.path, input.sourcePath, input.sourceHash, input.indexable ? 1 : 0, now, input.url);
      return "stale";
    },
    markInspection(url, result, inspectedAt) {
      if ("error" in result) {
        db.prepare("UPDATE urls SET verdict = 'error', last_error = ?, last_inspected_at = ?, updated_at = ? WHERE url = ?")
          .run(result.error, inspectedAt, inspectedAt, url);
        return;
      }
      db.prepare(`
        UPDATE urls
        SET verdict = ?, coverage_state = ?, last_crawl_time = ?, last_error = NULL, last_inspected_at = ?, updated_at = ?
        WHERE url = ?
      `).run(result.verdict, result.coverageState, result.lastCrawlTime, inspectedAt, inspectedAt, url);
    },
    listPending(budget, nowIso) {
      const retryBefore = new Date(Date.parse(nowIso) - 24 * 60 * 60 * 1000).toISOString();
      const rows = db.prepare(`
        SELECT * FROM urls
        WHERE indexable = 1
          AND (
            verdict IN ('unknown', 'stale', 'discovered', 'crawled_not_indexed')
            OR (verdict = 'error' AND (last_inspected_at IS NULL OR last_inspected_at <= ?))
          )
        ORDER BY last_inspected_at IS NOT NULL, last_inspected_at ASC, url ASC
        LIMIT ?
      `).all(retryBefore, budget) as Record<string, unknown>[];
      return rows.map(mapRow);
    },
    counts() {
      const counts = Object.fromEntries(VERDICTS.map((verdict) => [verdict, 0])) as Record<Verdict, number> & { private: number };
      counts.private = 0;
      const rows = db.prepare("SELECT verdict, indexable, COUNT(*) AS n FROM urls GROUP BY verdict, indexable").all() as { verdict: Verdict; indexable: number; n: number }[];
      for (const row of rows) {
        if (row.indexable === 0) counts.private += row.n;
        else counts[row.verdict] += row.n;
      }
      return counts;
    },
    indexableUrls() {
      return db.prepare("SELECT url, source_path AS sourcePath FROM urls WHERE indexable = 1 ORDER BY url ASC").all() as { url: string; sourcePath: string }[];
    },
    markSitemap(urls, at) {
      const stmt = db.prepare("UPDATE urls SET last_sitemap_at = ?, updated_at = ? WHERE url = ?");
      for (const url of urls) stmt.run(at, at, url);
    },
    urlsNeedingIndexNow() {
      const rows = db.prepare("SELECT url FROM urls WHERE indexable = 1 AND indexnow_at IS NULL ORDER BY url ASC").all() as { url: string }[];
      return rows.map((row) => row.url);
    },
    markIndexNow(urls, at) {
      const stmt = db.prepare("UPDATE urls SET indexnow_at = ?, updated_at = ? WHERE url = ?");
      for (const url of urls) stmt.run(at, at, url);
    },
    close() {
      db.close();
    },
  };
}

function mapRow(row: Record<string, unknown>): LedgerRow {
  return {
    url: String(row.url),
    path: String(row.path),
    sourcePath: String(row.source_path),
    sourceHash: String(row.source_hash),
    indexable: row.indexable === 1,
    verdict: String(row.verdict) as Verdict,
    coverageState: (row.coverage_state as string | null) ?? null,
    lastCrawlTime: (row.last_crawl_time as string | null) ?? null,
    lastInspectedAt: (row.last_inspected_at as string | null) ?? null,
    lastSitemapAt: (row.last_sitemap_at as string | null) ?? null,
    indexnowAt: (row.indexnow_at as string | null) ?? null,
    lastError: (row.last_error as string | null) ?? null,
    updatedAt: String(row.updated_at),
  };
}

export function buildSitemap(urls: { loc: string; lastmod?: string }[]): string {
  const body = urls.map((url) => {
    const lastmod = url.lastmod ? `\n    <lastmod>${escapeXml(url.lastmod)}</lastmod>` : "";
    return `  <url>\n    <loc>${escapeXml(url.loc)}</loc>${lastmod}\n  </url>`;
  }).join("\n");
  return `<?xml version="1.0" encoding="UTF-8"?>\n<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n${body}\n</urlset>\n`;
}

function escapeXml(value: string): string {
  return value
    .replaceAll("&", "&amp;")
    .replaceAll("<", "&lt;")
    .replaceAll(">", "&gt;")
    .replaceAll('"', "&quot;")
    .replaceAll("'", "&apos;");
}

import type { Verdict } from "./types.js";

export class QuotaExceededError extends Error {
  constructor() {
    super("Google URL Inspection daily quota exceeded");
    this.name = "QuotaExceededError";
  }
}

export interface Inspection {
  verdict: Verdict;
  coverageState: string | null;
  lastCrawlTime: string | null;
}

export function mapCoverage(verdict: string | undefined, coverageState: string | undefined): Verdict {
  const coverage = (coverageState ?? "").toLowerCase();
  if (coverage.includes("submitted and indexed")) return "indexed";
  if (coverage.includes("crawled") && coverage.includes("not indexed")) return "crawled_not_indexed";
  if (coverage.includes("discovered") || coverage.includes("unknown to google")) return "discovered";
  if (coverage.includes("excluded") || coverage.includes("noindex") || coverage.includes("blocked")) return "excluded";
  if ((verdict ?? "").toUpperCase() === "PASS" && coverage.includes("indexed")) return "indexed";
  return "unknown";
}

export async function inspectUrl(
  token: string,
  siteUrl: string,
  inspectionUrl: string,
  fetchImpl: typeof fetch = fetch,
): Promise<Inspection> {
  const response = await fetchImpl("https://searchconsole.googleapis.com/v1/urlInspection/index:inspect", {
    method: "POST",
    headers: {
      authorization: `Bearer ${token}`,
      "content-type": "application/json",
    },
    body: JSON.stringify({ inspectionUrl, siteUrl }),
  });
  if (response.status === 429) throw new QuotaExceededError();
  if (!response.ok) throw new Error(`URL Inspection failed: HTTP ${response.status}`);
  const body = await response.json() as {
    inspectionResult?: { indexStatusResult?: { verdict?: string; coverageState?: string; lastCrawlTime?: string } };
  };
  const status = body.inspectionResult?.indexStatusResult;
  return {
    verdict: mapCoverage(status?.verdict, status?.coverageState),
    coverageState: status?.coverageState ?? null,
    lastCrawlTime: status?.lastCrawlTime ?? null,
  };
}

export async function submitSitemap(
  token: string,
  siteUrl: string,
  feedUrl: string,
  fetchImpl: typeof fetch = fetch,
): Promise<void> {
  const target = `https://www.googleapis.com/webmasters/v3/sites/${encodeURIComponent(siteUrl)}/sitemaps/${encodeURIComponent(feedUrl)}`;
  const response = await fetchImpl(target, {
    method: "PUT",
    headers: { authorization: `Bearer ${token}` },
  });
  if (!response.ok) throw new Error(`Sitemap submit failed: HTTP ${response.status}`);
}

import fs from "node:fs";
import http from "node:http";
import path from "node:path";
import { GoogleAuth } from "google-auth-library";

const SCOPE = "https://www.googleapis.com/auth/webmasters";

interface TokenCache {
  access_token: string;
  refresh_token?: string;
  expiry_date: number;
}

export function credentialKind(json: unknown): "service_account" | "installed" | "unknown" {
  if (!json || typeof json !== "object") return "unknown";
  const record = json as { type?: string; installed?: unknown };
  if (record.type === "service_account") return "service_account";
  if (record.installed) return "installed";
  return "unknown";
}

export function readCachedAccessToken(cachePath: string, nowMs: number): string | null {
  if (!fs.existsSync(cachePath)) return null;
  const cache = JSON.parse(fs.readFileSync(cachePath, "utf8")) as TokenCache;
  if (!cache.access_token || cache.expiry_date - nowMs < 60_000) return null;
  return cache.access_token;
}

export async function getAccessToken(opts: {
  credentialsPath: string;
  tokenCachePath: string;
  openUrl?: (url: string) => void;
  fetchImpl?: typeof fetch;
}): Promise<string> {
  const cached = readCachedAccessToken(opts.tokenCachePath, Date.now());
  if (cached) return cached;
  const json = JSON.parse(fs.readFileSync(opts.credentialsPath, "utf8")) as unknown;
  const kind = credentialKind(json);
  if (kind === "service_account") {
    const auth = new GoogleAuth({ keyFile: opts.credentialsPath, scopes: [SCOPE] });
    const client = await auth.getClient();
    const token = await client.getAccessToken();
    if (!token.token) throw new Error("Google auth returned no access token");
    return token.token;
  }
  if (kind !== "installed") throw new Error("Google credential file must be a service account or installed app client");
  const refreshed = await refreshIfPossible(json, opts.tokenCachePath, opts.fetchImpl ?? fetch);
  if (refreshed) return refreshed;
  return authorizeInstalled(json, opts);
}

async function refreshIfPossible(json: unknown, cachePath: string, fetchImpl: typeof fetch): Promise<string | null> {
  if (!fs.existsSync(cachePath)) return null;
  const cache = JSON.parse(fs.readFileSync(cachePath, "utf8")) as TokenCache;
  if (!cache.refresh_token) return null;
  const installed = (json as { installed: { client_id: string; client_secret: string } }).installed;
  const body = new URLSearchParams({
    client_id: installed.client_id,
    client_secret: installed.client_secret,
    refresh_token: cache.refresh_token,
    grant_type: "refresh_token",
  });
  const response = await fetchImpl("https://oauth2.googleapis.com/token", {
    method: "POST",
    headers: { "content-type": "application/x-www-form-urlencoded" },
    body,
  });
  if (!response.ok) return null;
  const token = await response.json() as { access_token: string; expires_in: number; refresh_token?: string };
  writeCache(cachePath, token.access_token, token.refresh_token ?? cache.refresh_token, Date.now() + token.expires_in * 1000);
  return token.access_token;
}

async function authorizeInstalled(json: unknown, opts: {
  tokenCachePath: string;
  openUrl?: (url: string) => void;
  fetchImpl?: typeof fetch;
}): Promise<string> {
  const installed = (json as { installed: { client_id: string; client_secret: string } }).installed;
  const server = http.createServer();
  await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", () => resolve()));
  const address = server.address();
  if (!address || typeof address === "string") throw new Error("OAuth loopback failed to bind");
  const redirectUri = `http://127.0.0.1:${address.port}`;
  const authUrl = new URL("https://accounts.google.com/o/oauth2/v2/auth");
  authUrl.searchParams.set("client_id", installed.client_id);
  authUrl.searchParams.set("redirect_uri", redirectUri);
  authUrl.searchParams.set("response_type", "code");
  authUrl.searchParams.set("scope", SCOPE);
  authUrl.searchParams.set("access_type", "offline");
  authUrl.searchParams.set("prompt", "consent");
  const code = await new Promise<string>((resolve, reject) => {
    server.on("request", (request, response) => {
      const url = new URL(request.url ?? "/", redirectUri);
      const value = url.searchParams.get("code");
      response.statusCode = 200;
      response.end("Indexkit received the Google authorization code. You can close this tab.");
      server.close();
      if (!value) reject(new Error("Google redirect did not include a code"));
      else resolve(value);
    });
    (opts.openUrl ?? defaultOpen)(authUrl.toString());
  });
  const body = new URLSearchParams({
    code,
    client_id: installed.client_id,
    client_secret: installed.client_secret,
    redirect_uri: redirectUri,
    grant_type: "authorization_code",
  });
  const response = await (opts.fetchImpl ?? fetch)("https://oauth2.googleapis.com/token", {
    method: "POST",
    headers: { "content-type": "application/x-www-form-urlencoded" },
    body,
  });
  if (!response.ok) throw new Error(`Google token exchange failed: HTTP ${response.status}`);
  const token = await response.json() as { access_token: string; expires_in: number; refresh_token?: string };
  writeCache(opts.tokenCachePath, token.access_token, token.refresh_token, Date.now() + token.expires_in * 1000);
  return token.access_token;
}

function writeCache(cachePath: string, accessToken: string, refreshToken: string | undefined, expiry: number): void {
  fs.mkdirSync(path.dirname(cachePath), { recursive: true });
  const payload: TokenCache = { access_token: accessToken, expiry_date: expiry };
  if (refreshToken) payload.refresh_token = refreshToken;
  fs.writeFileSync(cachePath, JSON.stringify(payload, null, 2));

```ts
import path from "node:path";
import { hashFile } from "./fsutil.js";
import { QuotaExceededError, type Inspection } from "./gsc.js";
import type { Ledger } from "./ledger.js";
import { toUrl } from "./routes.js";
import { buildSitemap } from "./sitemap.js";
import type { RouteRecord } from "./types.js";

export interface RunDeps {
  project: string;
  origin: string;
  budget: number;
  ledger: Ledger;
  now: () => Date;
  collect: () => Promise<{ framework: string; routes: RouteRecord[] }>;
  inspect?: (url: string) => Promise<Inspection>;
  writeSitemap?: (xml: string) => string;
  submitSitemap?: () => Promise<void>;
  submitIndexNow?: (urls: string[]) => Promise<void>;
}

export interface RunReport {
  framework: string;
  discovered: number;
  indexable: number;
  skippedIndexed: number;
  inspected: number;
  newlyIndexed: number;
  errors: number;
  sitemapWritten: string | null;
  sitemapSubmitted: boolean;
  indexnowSubmitted: number;
  stoppedReason: "budget" | "quota" | "done";
}

export async function runDaily(deps: RunDeps): Promise<RunReport> {
  const now = deps.now().toISOString();
  const collected = await deps.collect();
  for (const route of collected.routes) {
    deps.ledger.upsert({
      url: toUrl(deps.origin, route.path),
      path: route.path,
      sourcePath: route.sourcePath,
      sourceHash: hashFile(path.join(deps.project, route.sourcePath)),
      indexable: route.indexable,
    }, now);
  }
  const indexable = deps.ledger.indexableUrls();
  let sitemapWritten: string | null = null;
  let sitemapSubmitted = false;
  if (deps.writeSitemap) {
    const xml = buildSitemap(indexable.map((row) => ({ loc: row.url })));
    sitemapWritten = deps.writeSitemap(xml);
    deps.ledger.markSitemap(indexable.map((row) => row.url), now);
    if (deps.submitSitemap && sitemapWritten) {
      await deps.submitSitemap();
      sitemapSubmitted = true;
    }
  }
  const pending = deps.inspect ? deps.ledger.listPending(deps.budget, now) : [];
  let inspected = 0;
  let newlyIndexed = 0;
  let errors = 0;
  let stoppedReason: RunReport["stoppedReason"] = pending.length >= deps.budget ? "budget" : "done";
  if (deps.inspect) {
    for (const row of pending) {
      try {
        const result = await deps.inspect(row.url);
        deps.ledger.markInspection(row.url, result, deps.now().toISOString());
        inspected += 1;
        if (result.verdict === "indexed") newlyIndexed += 1;
      } catch (error) {
        if (error instanceof QuotaExceededError) {
          stoppedReason = "quota";
          break;
        }
        errors += 1;
        deps.ledger.markInspection(row.url, { error: error instanceof Error ? error.message : "inspect failed" }, deps.now().toISOString());
      }
    }
  }
  let indexnowSubmitted = 0;
  if (deps.submitIndexNow) {
    const urls = deps.ledger.urlsNeedingIndexNow();
    for (let i = 0; i < urls.length; i += 10_000) {
      const chunk = urls.slice(i, i + 10_000);
      await deps.submitIndexNow(chunk);
      deps.ledger.markIndexNow(chunk, deps.now().toISOString());
      indexnowSubmitted += chunk.length;
    }
  }
  const counts = deps.ledger.counts();
  return {
    framework: collected.framework,
    discovered: collected.routes.length,
    indexable: indexable.length,
    skippedIndexed: counts.indexed,
    inspected,
    newlyIndexed,
    errors,
    sitemapWritten,
    sitemapSubmitted,
    indexnowSubmitted,
    stoppedReason,
  };
}
```

import fs from "node:fs";
import path from "node:path";
import { walkFiles } from "./fsutil.js";
import type { RawRoute, RouteRecord } from "./types.js";

const DISCOVER_SYSTEM = 'You extract HTTP page routes from a web app. Return a JSON array only. Each item is {"path":"/pricing","sourcePath":"app/pricing/page.tsx","dynamic":false}. path is the URL path. sourcePath must be one of the files you were given. Include only pages a search engine should be able to request. Omit API handlers, server actions, and asset files. No markdown.';
const CLASSIFY_SYSTEM = 'You label web routes as indexable or not. Return a JSON array only. Each item is {"path":"/pricing","indexable":true,"reason":"public page"}. Use only paths from the input. Mark indexable false for admin, auth, account, API, and draft pages. No markdown.';

export function extractJsonArray(text: string): unknown {
  const fenced = text.trim().match(/```(?:json)?\s*([\s\S]*?)```/);
  const body = fenced ? fenced[1] : text;
  const start = body.indexOf("[");
  const end = body.lastIndexOf("]");
  if (start < 0 || end < start) throw new Error("MiniMax response did not contain a JSON array");
  return JSON.parse(body.slice(start, end + 1));
}

export function acceptModelRoutes(parsed: unknown, allowedSourcePaths: Set<string>): RawRoute[] {
  if (!Array.isArray(parsed)) return [];
  const routes: RawRoute[] = [];
  for (const item of parsed) {
    if (!item || typeof item !== "object") continue;
    const record = item as { path?: unknown; sourcePath?: unknown; dynamic?: unknown };
    if (typeof record.path !== "string" || !record.path.startsWith("/")) continue;
    if (typeof record.sourcePath !== "string" || !allowedSourcePaths.has(record.sourcePath)) continue;
    routes.push({
      path: record.path,
      sourcePath: record.sourcePath,
      dynamic: record.dynamic === true || /[\[\]:]/.test(record.path),
    });
  }
  return routes;
}

export function candidateFiles(project: string): { path: string; text: string }[] {
  const interesting = /(page|route|router|server|nuxt\.config|astro\.config)\./i;
  return walkFiles(project, (abs) => interesting.test(path.basename(abs)) && /\.(js|jsx|ts|tsx|mjs|vue|svelte|astro|md|mdx)$/.test(abs))
    .slice(0, 30)
    .map((abs) => ({
      path: path.relative(project, abs),
      text: fs.readFileSync(abs, "utf8").slice(0, 6000),
    }));
}

export function createMiniMaxModel(opts: {
  apiKey: string;
  model?: string;
  baseUrl?: string;
  cachePath: string;
  fetchImpl?: typeof fetch;
}): {
  discoverFromFiles(input: { project: string; files: { path: string; text: string }[] }): Promise<RawRoute[]>;
  classify(routes: RouteRecord[]): Promise<RouteRecord[]>;
} {
  const model = opts.model ?? "MiniMax-M3";
  const baseUrl = opts.baseUrl ?? "https://api.minimax.io/v1";
  return {
    async discoverFromFiles(input) {
      const content = await chat(opts, baseUrl, model, DISCOVER_SYSTEM, JSON.stringify(input.files));
      return acceptModelRoutes(extractJsonArray(content), new Set(input.files.map((file) => file.path)));
    },
    async classify(routes) {
      const content = await chat(opts, baseUrl, model, CLASSIFY_SYSTEM, JSON.stringify(routes.map((route) => ({
        path: route.path,
        sourcePath: route.sourcePath,
      }))));
      const parsed = extractJsonArray(content);
      if (!Array.isArray(parsed)) return routes;
      const labels = new Map<string, { indexable: boolean; reason: string }>();
      for (const item of parsed) {
        if (!item || typeof item !== "object") continue;
        const record = item as { path?: unknown; indexable?: unknown; reason?: unknown };
        if (typeof record.path !== "string") continue;
        labels.set(record.path, {
          indexable: record.indexable === true,
          reason: typeof record.reason === "string" ? record.reason : "minimax",
        });
      }
      return routes.map((route) => {
        const label = labels.get(route.path);
        if (!label) return route;
        return { ...route, indexable: route.indexable && label.indexable, reason: label.reason };
      });
    },
  };
}

async function chat(
  opts: { apiKey: string; cachePath: string; fetchImpl?: typeof fetch },
  baseUrl: string,
  model: string,
  system: string,
  user: string,
): Promise<string> {
  const body = JSON.stringify({
    model,
    temperature: 0.1,
    messages: [
      { role: "system", content: system },
      { role: "user", content: user },
    ],
  });
  const key = createHash("sha256").update(body).digest("hex");
  const cache = readCache(opts.cachePath);
  if (cache[key]) return cache[key];
  const response = await (opts.fetchImpl ?? fetch)(`${baseUrl}/chat/completions`, {
    method: "POST",
    headers: {
      authorization: `Bearer ${opts.apiKey}`,
      "content-type": "application/json",
    },
    body,
  });
  if (!response.ok) throw new Error(`MiniMax failed: HTTP ${response.status}`);
  const json = await response.json() as { choices?: { message?: { content?: string } }[] };
  const content = json.choices?.[0]?.message?.content;
  if (!content) throw new Error("MiniMax response did not include message content");
  cache[key] = content;
  fs.mkdirSync(path.dirname(opts.cachePath), { recursive: true });
  fs.writeFileSync(opts.cachePath, JSON.stringify(cache));
  return content;
}

function readCache(cachePath: string): Record<string, string> {
  if (!fs.existsSync(cachePath)) return {};
  return JSON.parse(fs.readFileSync(cachePath, "utf8")) as Record<string, string>;
}

  cwd: string;
  stdout: (line: string) => void;
  stderr: (line: string) => void;
  env: NodeJS.ProcessEnv;
}

export async function main(argv: string[], io: Io = {
  cwd: process.cwd(),
  stdout: (line) => process.stdout.write(`${line}\n`),
  stderr: (line) => process.stderr.write(`${line}\n`),
  env: process.env,
}): Promise<number> {
  const { values, positionals } = parseArgs({
    args: argv,
    options: {
      project: { type: "string" },
      origin: { type: "string" },
      config: { type: "string" },
      budget: { type: "string" },
      submit: { type: "boolean" },
    },
    allowPositionals: true,
    strict: true,
  });
  const command = positionals[0];
  if (!command || !["discover", "status", "sitemap", "run"].includes(command)) {
    io.stderr("usage: indexkit <discover|status|sitemap|run> --origin https://example.com [--project dir]");
    return 1;
  }
  try {
    const config = loadConfig(io.cwd, {
      project: values.project,
      origin: values.origin,
      configPath: values.config,
      budget: values.budget ? Number(values.budget) : undefined,
    });
    const ledgerPath = path.join(config.project, ".indexkit/ledger.db");
    if (command === "status" && !fs.existsSync(ledgerPath)) {
      io.stdout("no ledger");
      return 0;
    }
    const model = buildModel(config.project, config.minimax, io.env);
    if (command === "discover") {
      const result = await collectRoutes({ project: config.project, samples: config.samples, model });
      for (const route of result.routes.filter((item) => item.indexable)) {
        io.stdout(toUrl(config.origin, route.path));
      }
      io.stderr(`${result.framework} indexable ${result.routes.filter((item) => item.indexable).length}`);
      return 0;
    }
    const ledger = openLedger(ledgerPath);
    try {
      if (command === "status") {
        const counts = ledger.counts();
        for (const [key, value] of Object.entries(counts)) io.stdout(`${key} ${value}`);
        return 0;
      }
      const report = await runDaily({
        project: config.project,
        origin: config.origin,
        budget: config.budget ?? 200,
        ledger,
        now: () => new Date(),
        collect: () => collectRoutes({ project: config.project, samples: config.samples, model }),
        inspect: command === "run" && config.siteUrl && credentialPath(config, io.env)
          ? async (url) => inspectUrl(await token(config, io.env), config.siteUrl as string, url)
          : undefined,
        writeSitemap: (xml) => {
          const out = path.resolve(config.project, config.sitemapOut ?? ".indexkit/sitemap.xml");
          fs.mkdirSync(path.dirname(out), { recursive: true });
          fs.writeFileSync(out, xml);
          return out;
        },
        submitSitemap: values.submit && config.sitemapPublicUrl && config.siteUrl
          ? async () => {
              await submitSitemap(await token(config, io.env), config.siteUrl as string, config.sitemapPublicUrl as string);
            }
          : undefined,
        submitIndexNow: config.indexnow?.key
          ? async (urls) => {
              const host = config.indexnow?.host ?? new URL(config.origin).host;
              const key = config.indexnow?.key ?? "";
              await submitIndexNow({
                host,
                key,
                keyLocation: config.indexnow?.keyLocation ?? `${config.origin.replace(/\/$/, "")}/${key}.txt`,
                urls,
              });
            }
          : undefined,
      });
      io.stdout(JSON.stringify(report));
      return 0;
    } finally {
      ledger.close();
    }
  } catch (error) {
    io.stderr(error instanceof Error ? error.message : "indexkit failed");
    return 1;
  }
}

function buildModel(project: string, setting: { discover?: boolean; classify?: boolean; model?: string; baseUrl?: string } | false | undefined, env: NodeJS.ProcessEnv) {
  const apiKey = env.MINIMAX_API_KEY;
  if (!apiKey || setting === false) return null;
  return createMiniMaxModel({
    apiKey,
    model: setting?.model,
    baseUrl: setting?.baseUrl,
    cachePath: path.join(project, ".indexkit/minimax-cache.json"),
  });
}

function credentialPath(config: { project: string; googleCredentials?: string }, env: NodeJS.ProcessEnv): string | undefined {
  return config.googleCredentials ?? env.GOOGLE_APPLICATION_CREDENTIALS;
}

async function token(config: { project: string; googleCredentials?: string }, env: NodeJS.ProcessEnv): Promise<string> {
  const credentialsPath = credentialPath(config, env);
  if (!credentialsPath) throw new Error("Set googleCredentials or GOOGLE_APPLICATION_CREDENTIALS");
  return getAccessToken({
    credentialsPath,
    tokenCachePath: path.join(config.project, ".indexkit/google-token.json"),
  });
}

if (import.meta.url === new URL(process.argv[1] ?? "", "file:").href) {
  main(process.argv.slice(2)).then((code) => process.exit(code));
}

```md
# indexkit

`indexkit` reads a local web app, finds its pages, writes a sitemap, and remembers which URLs Google has already indexed.

A daily run skips a URL when the ledger verdict is indexed and the source file hash is unchanged.

## What Google accepts

Google gives ordinary sites two relevant APIs:

- Sitemap submission through `sitemaps.submit` on the Search Console API. This hands Google the URL list. Submit the sitemap once per change.
- Status checks through `urlInspection.index.inspect`. This returns the indexed verdict, coverage state, and last crawl. The quota is about 2,000 inspections per day and 600 per minute per property. The default budget in this tool is 200.

The URL Inspection API has no method that requests indexing. The Indexing API is for pages with `JobPosting` or `BroadcastEvent` inside a `VideoObject`. `indexkit` does not call it. IndexNow is optional and notifies Bing and the other IndexNow engines. It does not notify Google.

A successful inspection or sitemap submit does not guarantee that a page will appear in Google Search.

## Setup

1. Create a Google Cloud project and enable the Google Search Console API.
2. Create a service account, or an OAuth desktop client.
3. For a service account, add its email as an owner of the Search Console property.
4. Save the credential JSON outside git. Point `googleCredentials` or `GOOGLE_APPLICATION_CREDENTIALS` at it.
5. Copy `indexkit.config.example.json` to `indexkit.config.json`.
6. Set `origin` to the public site and `siteUrl` to the property string exactly as Search Console shows it (`sc-domain:example.com` or `https://example.com/`).
7. Put dynamic sample values in `samples`. A route such as `/blog/[slug]` stays out of the sitemap until `slug` has values.
8. Host the IndexNow key file at the URL in `keyLocation` before enabling `indexnow`.

MiniMax is optional. Export `MINIMAX_API_KEY` when the framework is not recognized or when you want a public-versus-private label. The key stays in the environment. Set `"minimax": false` to disable it.

## Commands

```bash
npx indexkit discover --project ./app --origin https://example.com
npx indexkit sitemap --submit
npx indexkit run --budget 200
npx indexkit status
```

`discover` prints indexable URLs. `sitemap` writes `sitemapOut` (default `.indexkit/sitemap.xml`) and, with `--submit`, submits `sitemapPublicUrl`. `run` discovers, updates the ledger, writes the sitemap, inspects pending URLs, and sends new URLs to IndexNow when that block is configured. `status` prints ledger counts.

The ledger is `.indexkit/ledger.db` inside the project. It is gitignored.

## Daily use

Run `indexkit run` once a day from cron or from GitHub Actions. The command spends the budget on unknown, stale, discovered, and crawled-not-indexed URLs. Error rows wait 24 hours. Indexed rows wait until the source file changes.

## Development

```bash
npm install
npm test
npm run build
```

Node.js 22.5 or newer is required.

## Out of scope

- Calling `indexing.googleapis.com` for any route.
- Driving Chrome, Playwright, or Puppeteer against Search Console.
- Rotating Google Cloud projects to multiply the 200-request Indexing API quota.
- Deleting ledger rows when a route disappears.
- Crawling the live site to invent URLs that are not in the source.
- OAuth flows other than a service account or an installed-app loopback.
